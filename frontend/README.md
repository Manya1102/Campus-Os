# Campus OS frontend

React + Vite client for the Campus OS API. Start the backend first (`cd ../backend && npm run dev`), then run:

```bash
npm install
npm run dev
```

The API defaults to `http://localhost:5001/api`. Set `VITE_API_URL` in `frontend/.env` to use another API URL. See the repository [README](../README.md) for database setup, migrations, onboarding, and role behavior.
